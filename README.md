# ShelterMap USA — Presentation

Civil defense and emergency preparedness project for the United States: scenario guides, a live map of shelters, food, water and danger zones, and community reports.

**Live presentation:** https://veryhappyman84.github.io/presentation-shelter/

## How to view

Open the link above. Controls:

- Arrow keys, Space, or the on-screen buttons to move between slides
- Swipe left or right on a phone
- RU / EN button (top right) to switch language
- Print the page (Ctrl+P / Cmd+P) to save it as a PDF

## Files

- `index.html` is the whole presentation (no build step, no dependencies)
